## 🚀 Основные изученные концепции

### 1. Архитектура программных систем
* Разделение ответственности кода (Separation of Concerns) на бизнес-логику (пакет `services`) и презентационную логику вывода отчетов (`utils`) [image_a819oA.png].
* Корректная организация пакетов внутри модулей Python с использованием файлов `__init__.py`.

### 2. Изоляция окружения и воспроизводимость
* Управление локальными зависимостями проекта с использованием изолированных сред виртуального окружения (`.venv`).
* Фиксация пакетов в файле конфигурации `requirements.txt`.
* Настройка контроля версий с помощью `.gitignore` для предотвращения попадания системного и кэширующего мусора (`__pycache__`, `.venv`, `.pytest_cache`) в удаленный репозиторий [image_0SJrCz.png].

### 3. Автоматизированное тестирование
* Написание автоматических тестов с помощью оператора проверки условий `assert` [image_0SJrCz.png].
* Запуск тест-кейсов, проверка граничных сценариев и перехват ожидаемых исключений (`ValueError`) через фреймворк `pytest` [image_0SJrCz.png].

## 🛠 Общие команды для развертывания любого урока

Для запуска и проверки любого практического задания из папки `homework/` перейдите в целевую директорию урока и выполните стандартный цикл команд:

```bash
# 1. Создание виртуального окружения
python -m venv .venv

# 2. Активация окружения (для Windows)
.venv\Scripts\activate

# 3. Установка всех необходимых зависимостей
pip install -r requirements.txt

# 4. Запуск автоматических тестов для проверки работоспособности
python -m pytest -v
```
