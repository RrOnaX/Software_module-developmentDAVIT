# Проект: Cafe Report ☕

Скрипт автоматизации для формирования отчётов по выручке и заказам сотрудников кофейни. Проект реструктурирован из хаотичного набора файлов в структурированное Python-приложение в соответствии со стандартами PEP 8.

## 📂 Структура проекта

```text
cafe-report/
├── .env                     # Локальные переменные окружения и секреты (скрыты от Git)
├── .gitignore               # Конфигурация исключений системы контроля версий
├── README.md                # Документация проекта и описание архитектуры
├── data/                    # Исходные файлы данных
│   └── orders.csv           # База заказов за смену в формате CSV
├── docs/                    # Справочные материалы и исходные ТЗ
│   ├── ЗАДАНИЕ.md
│   ├── про проект.md
│   └── читать меня.md
├── tests/                   # Набор модульных тестов (unittest)
│   ├── __init__.py
│   ├── test_orders.py       # Тестирование бизнес-логики обработки заказов
│   └── test_report.py       # Тестирование утилит форматирования и генерации отчёта
└── app/                     # Основной пакет приложения
    ├── __init__.py
    ├── main.py              # Главная точка входа (скрипт запуска)
    ├── utils.py             # Объединённые утилиты форматирования строк и валют
    └── services/            # Модули внутренней бизнес-логики
        ├── __init__.py
        ├── orders.py        # Загрузка, фильтрация и расчёт показателей заказов
        └── report.py        # Компоновка и структурирование текстового отчёта
```

## 🚀 Инструкция по запуску

### Запуск основного приложения
Для формирования и вывода отчёта в консоль выполните следующую команду из корня проекта:
```bash
python -m app.main
```

### Запуск модульных тестов
Для проверки работоспособности модулей и запуска всех 9 встроенных тестов выполните:
```bash
python -m unittest discover -s tests -v
```
