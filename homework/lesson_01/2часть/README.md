# Проект: Text Kit 🛠️

Набор утилитарных функций и модулей для базовой предобработки, валидации и анализа текстовых и числовых данных. В рамках лабораторной работы исходный монолитный файл `main.py` был успешно декомпозирован на независимые пакеты и модули в соответствии с принципами единственной ответственности (SRP) и стандартом PEP 8.

## 📂 Структура проекта (Архитектура)

```text
text-kit/
├── README.md                # Описание проекта, команд запуска и структуры папок
├── ЗАДАНИЕ.md               # Исходное техническое задание
├── tests/                   # Набор модульных тестов для проверки работоспособности
│   ├── test_dates.py
│   ├── test_statistics.py
│   ├── test_text.py
│   └── test_validation.py
└── app/                     # Основной пакет логики приложения
    ├── __init__.py
    ├── main.py              # Точка входа (содержит демонстрационные константы и запуск)
    ├── utils/               # Вспомогательные утилиты общего назначения
    │   ├── __init__.py
    │   ├── text.py          # Обработка и форматирование строк (clean_spaces, shorten, initials, slug)
    │   └── dates.py         # Работа с временными типами данных (parse_date, format_date, is_weekend, days_between)
    └── services/            # Модули специфичной бизнес-логики проекта
        ├── __init__.py
        ├── statistics.py    # Математические расчёты (average, median, spread, count_values)
        └── validation.py    # Проверка корректности данных (is_email, normalize_phone, is_phone, password_problems)
```

## 🧠 Признак разделения функций по модулям
Функции распределены по четырем файлам на основе их контекстной зоны ответственности:
1. **Мелкие утилиты (`app/utils/`)**: Функции общего назначения, которые можно без изменений переносить в любой другой проект (изолированная работа со строками или системными типами дат).
2. **Бизнес-логика (`app/services/`)**: Функции, реализующие правила конкретно текущего проекта (проверка паролей, специфичная валидация номеров телефонов, кастомный подсчет медиан и средних значений для отчетов).

## 🚀 Команды для проверки

### Запуск демонстрационного скрипта
Для запуска приложения и вывода результатов работы в консоль выполните:
```bash
python -m app.main
```

### Запуск автоматических тестов
Для проведения полной диагностики кодовой базы и выполнения всех 19 тестов используйте:
```bash
python -m unittest discover -s tests -v
```
