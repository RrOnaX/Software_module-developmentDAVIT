## ☕ Работа 1: Иерархия проекта «Cafe Report»

**Основная задача:** Сборка хаотичной кучи из 17 файлов в структурированное приложение с изоляцией секретов.

### Ключевые изменения:
* Организована папка `data/` для хранения файлов данных отдельно от логики.
* Создан файл `.gitignore` для защиты секретного токена `REPORT_TOKEN` в файле `.env` от попадания в публичный доступ.
* Код разделен по уровням: мелкие функции вынесены в `utils.py`, а тяжелая аналитика — в пакет `services/`.

### Команды для проверки:
```bash
# Перейдите в папку проекта
cd cafe-report

# Запуск формирования отчета
python -m app.main

# Запуск 9 встроенных тестов
python -m unittest discover -s tests -v
```

## 🛠️ Работа 2: Модульность «Text Kit»

**Основная задача:** Распил огромного монолитного скрипта `main.py` из 16 разнородных функций на 4 специализированных модуля.

### Ключевые изменения:
* **utils/text.py & utils/dates.py** — изолированные инструменты для строк и дат, готовые к повторному использованию в других проектах.
* **services/statistics.py & services/validation.py** — модули специфичной логики приложения (анализ паролей, расчёт медиан).
* Настроена межмодульная связь: импортирована очистка строк в пакет валидации данных.

### Команды для проверки:
```bash
# Перейдите в папку проекта
cd ../text-kit

# Запуск демонстрационного скрипта
python -m app.main

# Запуск 19 встроенных тестов
python -m unittest discover -s tests -v
```
